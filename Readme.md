AI Learning & Study Assistant

A responsive front-end mini project for an AI-powered student learning dashboard.


Features


AI Tutor / Q&A demo

Subject and topic selection

Notes and summaries

Quiz / MCQ generator

Flashcards

Study planner

Progress dashboard

Mobile-friendly responsive design


Run locally


Download or unzip the project.

Open index.html in a browser.

For development, you can also use VS Code with the Live Server extension.


Important

The included AI Tutor is a front-end demo with sample responses. To make it a real AI application, connect the JavaScript tutor function to a secure backend and an AI API. Never expose a private API key directly in browser JavaScript.
